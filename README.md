# Slim – IAM2

Repozytorium z zadaniami z frameworka [Slim](https://www.slimframework.com/) realizowanymi na uczelni (przedmiot IAM2, Uniwersytet Śląski).

Każde zadanie to osobny projekt Slim 4 w swoim folderze.

| Zadanie | Opis |
|---|---|
| [Zadanie1](Zadanie1) | API kalkulatora (`/calculate?a=10&b=5&operation=add`) |

## Wymagania

- PHP 8.1+
- Composer

## Uruchomienie dowolnego zadania

```bash
cd Zadanie1
composer install
php -S localhost:8080 -t public
```
